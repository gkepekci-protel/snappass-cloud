1. Application (AppKey) oluşturma

SnapPass için ayrı bir uygulama kaydedilir; AppKey bu uygulamadan alınır.

  1. Oracle Hospitality Developer Portal'a (Customer Portal üzerinden) girin → üst menüden Applications → My Applications sekmesi.
  2. Sağ üstteki Register Application düğmesine basın. Form birkaç adımdır; ilk adım Application Details'tir.

Kayıt sonrası

  • Kayıt bitince uygulama Applications listesinde New etiketiyle, en üstte görünür (ör. Kimlik Bildirim Sistemi · Production).
  • Kartta Application Key maskeli gösterilir (yalnız son 4 hane görünür). Copy ile anahtar panoya kopyalanır; SnapPass'taki AppKey alanına yapıştırılır. Tam anahtarı e-posta ya da sohbetle paylaşmayın.
  • Ayrıntılar için kartın altındaki View details açılır. Overview sekmesi uygulamanın açıklamasını, ortamını, iş gerekçesini ve onay beyanını gösterir; diğer sekmeler: Subscriptions, Events, Analytics, Alerts.
  • Application Key satırında Show (göster), Copy (kopyala) ve Reissue (yeniden üret) düğmeleri vardır. Reissue eski anahtarı geçersiz kılar; SnapPass'ta o anahtarı kullanan bağlantı kopar, yeni anahtarı OHIP formuna yeniden girmek gerekir.

2. Client ID oluşturma

Client ID, uygulamanın OHIP'e hangi otel ortamı (Environment) üzerinden bağlanacağını belirler.

  1. Developer Portal'da üst menüden Environments'a girin. My Environments sekmesinde otelin ortamı listelenir (ör. MAG COWORK ISTANBUL (mtce2-oc) · Production · Streaming Enabled · Germany Central (Frankfurt)). Ortam adındaki kod (örnekte mtce2-oc) HostName'in ilk bölümüdür.
  2. Ortamın kartındaki View Details'e basın.
  1. Ayrıntı sayfasında Add Client'a basın. Sihirbaz 4 adımdır: Client Details → Modules → Assigned Hotels → Summary.

Adım 1 / 4 · Client Details

  • Client Name \*: istemcinin adı (ör. SnapPass). Sonra bu adla tanınır.
  • Next ile Modules adımına geçilir.

Adım 2 / 4 · Modules

Sayfanın üstünde Permissions set for 0 of 40 modules yazar; hiçbir modül seçili gelmez.

  1. Sensitive Data bölümündeki Grant Sensitive Data Access anahtarını AÇIK yapın (kimlik no okunabilsin diye). Bu ayarı client'ı oluştururken burada açmak yeterlidir; sonradan Edit ile de değiştirilebilir.
  2. Configure Module Permissions listesinden SnapPass'ın kullandığı modülleri seçin (modül adını açıp izinleri işaretleyin; bir izin seçilince bağımlı izinler başka modüllerde kendiliğinden açılabilir):
    SnapPass'ın yaptığıListedeki modül
    Rezervasyon arama / okuma, beraberindeki eklemeReservation
    Misafir profili okuma / güncelleme, kimlik belgesi yazmaCustomer Relationship Management ve API for Customer Management Service
    Zincir ve otel adı, zincirin otelleriEnterprise Configuration
  3. Kolay yol: listenin başındaki All Modules kutusunu işaretlemek 40 modülün tümünü (tüm izinleriyle) seçer. Dar yol: yalnız yukarıdaki modülleri seçmek istemcinin yetkisini sınırlar; kimlik no gibi hassas veriye erişimi olan bir istemci için tercih edilir.
  4. Next ile Assigned Hotels adımına geçin.

Adım 3 / 4 · Assigned Hotels

  • Ortamdaki oteller listelenir (otel adı ve Property kodu, ör. MAGIST). İstemcinin erişeceği otelleri işaretleyin; All hotels kutusu hepsini seçer. Sayfada 1 selected out of 1 gibi seçili sayı görünür.
  • SnapPass'a girilecek HotelId, buradaki Property kodudur (ör. MAGIST).
  • Next ile Summary adımına geçin.

Adım 4 / 4 · Summary

  • Özet ekranında seçimleri kontrol edip oluşturma düğmesine basın. İşlem bitince Client ID ve Client Secret gösterilir.
  • Client Secret'ı bu ekrandan hemen kopyalayıp güvenli bir yere (doğrudan SnapPass'taki OHIP formuna) yapıştırın; sonradan yeniden görüntülenemeyebilir. Kaybolursa Oracle'da yenisi oluşturulur.
  • Client ID ve Client Secret'ı sohbet, e-posta ya da ekran görüntüsüyle paylaşmayın.

3. Module Level Access Control

  1. Otelin (ya da Enterprise'ın) Customer Portal'ına girin.
  2. Sağ üst köşedeki kullanıcı menüsünü açın → Global Administration.
  3. Controls bölümünde Module Level Access Control anahtarına bakın: zaten AÇIK ise bir şey yapmayın, KAPALI ise AÇIK yapın.

4. Sensitive Data

Sensitive Data kapalıysa kimlik no bilgisi okunamaz.

  1. Kullanılan Client ID'nin Environment tanımına Manage ile girin.
  2. Edit → Module Permissions → Sensitive Data → Grant Sensitive Data Access anahtarına bakın: kapalıysa AÇIK yapın, açıksa dokunmayın.
  3. Customer ortamında bu ayar Customer Portal'daki ilgili Environment tanımındadır.
  4. Partner ortamında ayar, otelin kayıtlı olduğu Customer Portal'da (Developer Portal) Environments → Partner Connections sekmesindedir (aşağıya bakın).

Partner ortamı için (Partner Connections)

  1. Developer Portal → Environments → Partner Connections sekmesi. Listede otelin ortamı görünür (ör. MAG COWORK ISTANBUL (mtce2-oc) · Production · Germany Central (Frankfurt)); soldaki okla açılınca altında bağlı partner tanımı çıkar.
  2. Turkey tanımına (ör. turkey, durumu Approved) girin. Sayfada Environment Details, Module Permissions (Permissions set for 40 of 40 modules) ve Assigned Hotels (ör. 1 selected out of 1 · MAGIST) bölümleri bulunur; ikisinin de sağında Edit düğmesi vardır.
  3. Module Permissions → Edit açılan pencerede Sensitive Data altındaki Grant Sensitive Data Access anahtarına bakın: zaten AÇIK ise bir şey yapmayın, KAPALI ise AÇIK yapın. Aynı pencerede modüller listelenir (All Modules hepsini seçer). Save ile kaydedilir.
  4. Sayfanın altında Cancel, Revoke Access ve Update düğmeleri bulunur. Değişiklik sonrası Update etkinleşirse ona basın. Revoke Access partner bağlantısının erişimini iptal eder; yanlışlıkla basılırsa SnapPass bağlantısı kopar.

5. SnapPass'a girilecek bilgiler

Elinizde şunlar olmalı: AppKey (Applications → ilgili uygulamanın kartı → Copy), Client ID ve Client Secret (Add Client → Summary), HostName, EnterpriseId. HostName, ortamın ayrıntı sayfasındaki Gateway URL değeridir (ör. mtce2-oc ortamı için https://mtce2-oc.hospitality-api.eu-frankfurt-1.ocs.oraclecloud.com biçiminde).

Yukarıdaki adımlar bitince SnapPass yönetim panelinde: yeni otelde ➕ Otel ekle, mevcut otelde otel sayfasındaki OHIP Tanımları (zincirde Enterprise sayfası) bölümüne HostName, AppKey, EnterpriseId, CLIENT_ID, CLIENT_SECRET ve Ortam'ı girip Kaydet ve OHIP TEST ile bağlantıyı deneyin.
